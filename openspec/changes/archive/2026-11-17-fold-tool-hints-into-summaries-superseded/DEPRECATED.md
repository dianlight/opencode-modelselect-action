# Deprecated

Not implemented. Superseded on 2026-11-17 by `plugin-switched-off-state`.

`plugin-switched-off-state` already replaces the boolean presence regex with an
explicit presence state and moves the extension-card fix text into the
`needsConfiguration` card text. The change this proposal proposed (fold the
multi-sentence fix hint into a short summary) is the card-text half of that
broadening, so the narrower change is superseded.
